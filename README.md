# 福州大学材料科学与工程学院反诈模拟演练网站

## 项目用途

本项目用于福州大学材料科学与工程学院反诈主题班会模拟演练。它通过“校园信息通知—身份验证—反诈揭晓”的短流程，帮助同学识别熟人冒充、时间压力、陌生网址、验证码索取和缺乏二次核实等风险点。演练目的只在最终安全提醒页面揭晓。

本页面是课堂演练素材，并非福州大学真实业务系统，也不仿制真实统一身份认证页面。

## 安全说明

- 这是纯前端静态页面，不需要服务器或数据库。
- 不会保存密码、验证码或敏感个人信息。
- 不会向任何服务器发送用户输入。
- 不使用 Cookie、LocalStorage、SessionStorage、IndexedDB 或浏览器指纹。
- 不读取剪贴板，不请求定位、摄像头、麦克风或通讯录权限。
- “获取验证码”仅显示约 700ms 的本地模拟状态，不会发送短信。
- 姓名、班级、学号、手机号和验证码只短暂存在当前页面内存中；手机号仅生成脱敏显示值，切换阶段时原始输入会立即清空，刷新页面后不会保留。

部署时不要加入任何表单收集服务、统计上传服务、第三方脚本、Webhook、登录接口、短信接口或支付服务。

## 使用方法

1. 将经过允许使用的 `fzu-logo.png` 放进 `assets` 文件夹。若文件不存在，页面会显示“福州大学 Logo”占位框。可选放入经过授权的 `campus-bg.jpg` 作为校园背景；缺少时自动使用蓝色背景。
2. 在本地直接打开 `index.html`，或将整个 `anti-fraud-demo` 文件夹部署到静态网页托管服务。
3. 演练结束后关闭网站。

## 演练使用建议

- 仅在老师、辅导员知情同意的课堂活动中使用。
- 分享时明确控制使用范围，演练结束后及时撤下链接。
- 揭晓页面必须保留，不应改成真实登录、支付或信息收集流程。
- 不要把页面部署到容易被误认为学校官方域名的地址。
